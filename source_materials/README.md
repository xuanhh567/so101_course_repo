# 来源材料

这里保存的是手工搭建的 Word 来源材料，用于后续参照、比对和提炼。读者主路径应以 Markdown 教程为准；如果 Word 中有更完整或更准确的内容，应把它提炼进 `labs/`、`primer/` 或 `basic_operation/`。

| 文件 | 用途 | 后续处理 |
|------|------|----------|
| `预实验：LeRobot 环境创建.docx` | 环境创建与预实验来源材料 | 提炼到环境安装、CLI 验证和故障排查相关 Markdown |
| `模块一：物理基座构建与遥操作.docx` | 物理基座、主从臂和遥操作来源材料 | 提炼到主线教程第一段、第二段和操作补查章节 |
| `实验一：物理基座构建与遥操作.docx` | 硬件搭建、设备识别、遥操作实验来源材料 | 提炼到 `labs/01_lab_env_mapping_calibration.md` 和 `labs/02_lab_teleop_record_replay.md` |
| `实验二：专家示范与高质量数据工程.docx` | 专家示范、数据采集和数据工程来源材料 | 提炼到数据采集、回放和后续数据质量教程 |

提炼原则：

- 只把对教程主线有帮助的内容转成 Markdown。
- Word 文件保留为来源，不作为最终阅读路径。
- 转写时保留可执行命令、参数来源和自检方式。
