# Plan 02-01: Normalize And Connect The Three Main Labs

<objective>
Make `labs/01_lab_env_mapping_calibration.md`, `labs/02_lab_teleop_record_replay.md`, and `labs/03_lab_act_train_deploy.md` read as one continuous tutorial path. Each lab must expose previous outputs, current goals, next usage, parameter sources, expected effects, practice records, and self-checks without introducing grading or a second main path.
</objective>

<must_haves>
- D-01: Each `labs/` page explicitly shows how it connects to the previous and next tutorial segment.
- D-02: Each lab includes a short continuity block with `上一段产物`, `本段要完成`, and `下一段会用到什么`.
- D-04: Each lab uses the tutorial template: goal, preparation, steps, parameter sources, expected effects, practice records, and self-checklist.
- D-05: `练习记录` and `自检清单` remain reader self-checks, not scoring.
- D-06: Placeholder sources are explained near device, dataset, output, and checkpoint commands.
- D-07: Labs include short concept notes only where the concept affects the operation, with links to `primer/`.
- D-13: `basic_operation/` remains lookup reference material, not a second main path.
- D-16: Tool usage guidance appears where detector output is needed for commands.
</must_haves>
