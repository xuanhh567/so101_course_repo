# Structure

## Top Level

- `README.md`: Course overview and main navigation.
- `AGENTS.md`: Repository working instructions.
- `.planning/`: GSD project context, requirements, roadmap, and codebase map.
- `.gitignore`: Local Python cache ignore rules.

## Course Content

- `primer/00_course_map.md`: Course chain and learning model.
- `primer/01_so101_intro.md`: SO-101 introduction.
- `primer/02_lerobot_intro.md`: LeRobot introduction.
- `primer/03_embodied_data_intro.md`: Data collection concepts.
- `primer/04_act_intro.md`: ACT concepts.
- `labs/01_lab_env_mapping_calibration.md`: Environment, device mapping, and calibration.
- `labs/02_lab_teleop_record_replay.md`: Teleoperation, recording, and replay.
- `labs/03_lab_act_train_deploy.md`: ACT training and policy deployment.
- `basic_operation/`: Detailed reference chapters for the same workflow.

## Tooling

- `tools/detect_system.py`: Hardware detector and screenshot exporter.
- `tools/devices/device_simple.json`: Current or sample detector output.
- `tools/devices/images/`: Camera screenshots generated by detector.

## Source Material

- `source_materials/*.docx`: Original teaching reform documents copied into the new repository for preservation and future extraction.
